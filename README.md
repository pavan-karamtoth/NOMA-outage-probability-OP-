# NOMA-outage-probability-OP-Analysis
This repository presents the analytical derivation and Monte-Carlo simulation of outage probabilities for a two-user NOMA system with near and far users. The system considers Rayleigh fading channels, power-domain NOMA, and successive interference cancellation (SIC).

The outage probability for the near user is derived in closed form, accounting for both SIC decoding failure and self-decoding failure. Monte-Carlo simulations are performed to validate the analytical expression. Additionally, simulation results for the far user outage probability are obtained and compared with the analytical expression derived in class.

Simulation results illustrate the impact of transmit power on outage performance for both users. Analytical and simulation curves are plotted together to verify accuracy. The results confirm that the near user achieves lower outage probability due to SIC and better channel conditions.
